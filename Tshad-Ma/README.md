# Tshad-Ma — ཚད་མ་ textbooks by smaller independent authors

This folder collects Unicode plaintext ཚད་མ་ (pramāṇa) textbooks — བསྡུས་གྲྭ་ (bsdus grwa), བློ་རིག་ (blo rig) and རྟགས་རིགས་ (rtags rigs) — by smaller, independent authors of the Gelug scholastic world, as a complement to the famous masters' works held elsewhere in the archive (Purchok, Jetsun, Tsongkhapa, Gyaltsab Je, Khedrup Je in `Sungbum/` and `Commentaries/`).

Plaintext only, per the archive's rule. Each file is catalogued in `catalogue.json` (same schema as `Commentaries/commentary_names.json`; all entries tier 5).
