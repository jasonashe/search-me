# Gelug-Madhyamaka/

Important Gelugpa Madhyamaka (dBu ma) texts **not already held** in the search-me archive.

The archive already contains the core Gelug Madhyamaka canon — Tsongkhapa's *Dgongs pa rab gsal*, *Rtsa shes tik chen* and *Legs bshad snying po*, Gyaltsab's commentaries, Khedrup Je's *Skal bzang mig 'byed*, Jamyang Shepa's *mtha' dpyod*, Jetsun Chokyi Gyaltsen's *Bskal bzang mgul rgyan*, and others — under `Sungbum/DBU MA_…/`. This folder fills the gaps: major works and commentaries by authors not otherwise represented, plus commentaries on Tsongkhapa's own Madhyamaka texts by lesser-known Gelug authors.
